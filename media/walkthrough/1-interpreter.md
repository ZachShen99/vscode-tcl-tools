# Pick an interpreter

Tcl Tools learns your commands and packages from a real `tclsh`, and uses it to run and debug your code.

- Use Tcl **8.6 or newer**. The macOS system `tclsh` is 8.5 and lacks `lmap` and `try`.
- You can also click the Tcl version in the status bar.
- Using a host tool such as Vivado? See section 2 of the user guide.
