# Try the sample file

The sample is a small script with a namespace, a proc and one deliberately misspelled command. It opens as a normal file, so you can edit, run and debug it.

Things to try:

- Completion: type `geometry::`.
- Hover over `puts` or `geometry::area`.
- Go to definition: hold `Cmd/Ctrl` and click a proc name.
- Workspace symbols: `Cmd/Ctrl+T`.
